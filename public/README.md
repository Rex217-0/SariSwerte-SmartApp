## Background ng tindahan

Ilagay dito ang litrato ng tunay na tindahan, pangalanang:

    backdrop.jpg     (o backdrop.png / backdrop.webp)

Ito ang magiging dingding sa likod ni INDAY. Walang rebuild na kailangan:
i-reload lang ang page, makikita na agad.

Mga dapat tandaan:

- **Landscape** ang pinakamaganda (hal. 1600x900). Kung portrait, puputulin sa
  gilid para magkasya.
- Kung wala ang file, mananatili ang berdeng dingding. Hindi ito error.
- Kung mali ang file (hal. HTML na na-save bilang .jpg), hindi ito tatanggapin
  at mananatili ang berdeng dingding — sinasadya ito para hindi lumabas ang
  sirang larawan.
- Inirerekomenda: kuha mula sa loob ng tindahan, harap sa mga shelf, para
  magtugma ang paningin ni INDAY sa paligid.
